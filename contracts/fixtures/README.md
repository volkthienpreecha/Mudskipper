# Fixtures

Generated by contracts/make_fixtures.py (stdlib only, seed 20261114). Do not edit by hand: change the generator and run `make fixtures`.
`make fixtures-check` fails if these files differ from a fresh run.

Everything here is **SAMPLE** data: every file carries `"fixture": true` and every granule id starts with
`SAMPLE_`. The app shows the SAMPLE DATA badge for it, and nothing here may appear on the project page as a
finding.

| Path | What |
|---|---|
| `run/` | A complete published run (`run_id` `fixture`) shaped exactly like `artifacts/<run_id>/` |
| `api/` | One response per API endpoint, built from `run/`, plus a golden audit request and response |
| `live.json` | What R2 `live.json` looks like when the fixture set is live |

What is real and cited: the NISAR data gap, the GCOV granule naming format and the descending pass cadence
over both tiles, the 2026 Punjab DSR district figures (in `district_check.json`), and the parameter
citations (in `detectability.json`). Field shapes, radar values, states and claims are synthetic.
