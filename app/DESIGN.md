# Design context

The authoritative design is IshaanLingichetty/mudskipper-redesign at 78e30453e48eca0c2c1dc6db2d172bd3fc9d4423, imported at the user's explicit request. Preserve its photographic Earth/field scenes, dark ink palette, teal/coral model states, country-to-district-to-field composition, hero preview and section order. Use the Apple-first system sans serif stack throughout: -apple-system, BlinkMacSystemFont, system-ui, Segoe UI, sans-serif. San Francisco is supplied by Apple devices; other platforms use their native system sans serif. Do not redistribute Apple font files. Use regular body text, semibold headings, normal tracking, rem-based interface typography and tabular numerals for measurements. Touch controls have at least 44px targets; small text sits on opaque dark reading surfaces, with visible keyboard focus and support for reduced motion, increased contrast and text enlargement. Polish spacing, readability, responsive layout and controls without substituting another dashboard design. Remove highlighted status/evidence tags, the hero metric pill, Limits section, emoji and defensive copy. Source attribution and factual run metadata remain ordinary text.

The source-owned r01v1 snapshot is the default: 375 real segments and nine July–October dates with supplied states, classifier confidence and HH. Confidence is not flooded probability or accuracy. An explicit dataset selector loads the published API run as a coherent alternate dataset; its geometry, states, pass IDs, observations, summaries and audit results stay together. Never attach sample API values to snapshot field IDs. Backend analysis follows the selected run and uses the shared core math. The previous frontend is in git history at commit f964c52 (`app/legacy/solid-dashboard`).
